# UPC 数据目录

## 本机验收发布包

`release/` 是本机验收封版的脱敏、可重建公开业务目录，包含 17 个教学单位、1 个学期、
1555 个公开教师身份、1342 门课程、2946 条开课关系和 44 个导入批次摘要。它不包含
认证账号、用户档案、评价正文、积分、点赞、`imported_by`、数据库 dump、浏览器状态或
个人联系方式；教师姓名、公开职称/单位和课程关系属于重建业务目录所必需，予以保留。
导出命令：

```powershell
node --env-file=.env.import.local scripts/export-upc-release.mjs
```

导出文件与哈希见 `release/manifest.json`；边界与重建步骤见 `release/README.md`。
原始 `课表/` XLS 二进制只保留在本机，不进入仓库；其哈希和解析结果已包含在下述数据中。

## 课程身份与冲突

- 课程有正式编码时以编码为全局身份；同一名称可有多个编码，不合并。
- 同编码不同名称/开课单位必须记录并核实，不能改号或放宽约束。
- 本轮发现 `OTH921331020 沟通与写作` 在化学、机电、储建、材料、经管、外国语、文法、马院
  以不同开课单位出现；冲突涉及 8 个课程变体（含外国语），化学既有 1 门/1 条关系保留，
  新增实际排除 7 门/23 条关系，明细见 `timetables-2026-2027-1/conflicts.json`。
- 无编码课程只在 `(name, college)` 内匹配；若同学院同名已有编码课程，则无编码导入
  判为歧义并排除。

## 导入格式

```json
{
  "schemaVersion": 1,
  "dataset": "upc-chemistry-2026-2027-1-timetable-20261022",
  "source": "课表原始文件哈希 + 官方教师页 URL",
  "term": {
    "code": "2026-2027-1",
    "name": "2026-2027-1",
    "isCurrent": false
  },
  "teachers": [
    {
      "sourceId": "官方页面中的稳定教师编号或官方详情页文章 ID",
      "name": "教师姓名",
      "title": "教授",
      "collegeCode": "upc-03",
      "campus": null,
      "courses": [
        { "code": "CHM121711035", "name": "化学工程基础", "collegeCode": "upc-03" }
      ]
    }
  ]
}
```

- `sourceId` 必填且全局唯一；同名教师不得按姓名合并。
- `collegeCode` 是教师人事归属；`courses[].collegeCode` 是开课单位，二者可不同。
- 课程有正式编码时以编码区分；同名不同编码允许并存。无编码课程才使用
  `(name, college)` 唯一约束。
- 同编码不同名称、同学院同名课程同时存在有编码/无编码记录时，导入报冲突，不静默改号。
- `title`、`campus` 无法核实时留空/省略，不填猜测值。
- 有 `courses` 时必须提供 `term`；否则整批拒绝。
- `dataset` 以 `fixture-` 开头时，必须显式传 `--allow-fixture`，只能用于本地验证。

```powershell
npm run data:all-colleges

```
