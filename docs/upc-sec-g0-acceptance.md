# SEC-G0 有限验收矩阵（2026-10-24）

本文件把 SEC-G0 从“历史全套页面未重跑”改为**按当前产品规则定义的有限清单**。
判定口径：

- **代码完成**：源文件与生成物一致，类型检查/构建通过；
- **隔离验证**：独立 native Supabase 栈上的真实 Auth/PostgREST/浏览器通过；
- **现有库已生效**：五份补丁已应用到 WSL 目标库，post-check 与目标库会话验收通过；
- **云端数据库/Auth 已迁移**：托管项目专项检查通过；**完整 79 项云端 E2E、外部 SMTP、域名/TLS、发布回滚未执行**。

SEC-G0 的“通过”表示隔离验证通过；WSL 和云端数据库已另行迁移/专项验收，不表示完整云端或生产通过。

## 1. 范围定义

纳入：

1. 学生 `@s.upc.edu.cn` 注册确认、登录、退出、密码找回、邮箱变更；
2. Gmail 管理员私有邀请、稳定 `user_id` 授权、AAL1/AAL2；
3. 教师/课程检索、筛选、分页、详情、空数据、请求失败；
4. 个人中心、签到/积分；
5. 六维 4.0–5.0、一位小数、无文字评论；
6. 评价提交、修改重审、通过、驳回、点赞/取消；
7. 资料/授课关系纠错、实际写回、重导入保护；
8. 举报、作者撤回、注销及失败恢复；
9. 小样本隐藏、5 人门槛公开、撤回/举报后降级；
10. 普通用户、moderator、admin、super_admin 的权限边界；
11. 旧库五补丁升级路径（在隔离克隆验证，不执行现有库）。

不纳入（明确不适用/已删除）：

- 教师评分申诉入口、外部申诉渠道、后台代录；
- 公开文字评论、公开昵称、评价者身份；
- 非学生域自助注册、学校域管理员邀请；
- 公开的管理员 MFA 自助恢复后门；
- 旧版 1–5 分/评论/精确时间的“历史全套页面”复跑——这些页面已不属于当前规则；
- 云端/生产发布本身（属于后续 P4，不是 SEC-G0 隔离门槛）。

## 4. 结果判断

- **SEC-G0 隔离验收：通过**，按上述有限清单，不再以“历史全套页面未重跑”作为无限阻塞。
- **WSL 目标库：五补丁已执行并通过 post-check**；数据计数不变；专用账号会话失效/
  恢复验收 10/10。新 Gmail 管理员已建 Auth 账户，已完成密码设置和 TOTP 绑定。
- **云端完整/生产：未验收**；云端数据库已迁移并做专项检查，但完整 79 项 E2E、外部 SMTP、域名/TLS、真实 Gmail 投递、发布回滚仍属后续。
- **P1-02：运营信息冻结，未完成**；运营者明确本轮不修改、不再追问，仍不能作为已发布政策。
- **MFA 恢复：隔离演练 23/23 通过**；真实管理员恢复仍需运营者身份核验、变更单和授权。
- **恢复的 token 边界**：session/refresh 已撤销；管理员校验绑定 `auth.sessions`，旧 AAL2
  access token 的审核、邀请、身份查询和管理投影均被拒绝；普通用户接口仍可能接受未过期的
  签名 JWT，高风险场景可缩短 JWT TTL。无需用全局轮换签名密钥解决单个管理员恢复。
