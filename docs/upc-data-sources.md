## 教师身份核实口径

- 以官方教师列表中的姓名 + 官方个人详情页/CV 为准；`sourceId` 取自详情页文章路径
  （如 `cce-c19254-a365302`）或 CV 文件 UUID（如 `sem-cv-...`），不由姓名或姓名哈希生成。
  同一文章被多个栏目镜像时按“站点 + 文章 ID”合并，sourceId 保留最小栏目前缀。
- 只保存姓名、职称、系室和官方页面 URL；**不保存**邮箱、电话等联系方式。
- 同一姓名在同一来源有多个不同文章 ID 时标为歧义，不自动选择；同名教师不跨学院合并。
  仅凭姓名+学院页面不能完全排除跨学院同名教师，后续最好用教工号复核。
- 不同学院课表中出现的同名教师，只有在**该来源单位的官方列表/个人页**有唯一 profile
  （或同一 profile 被来源单位官方列表交叉列出）时才复用；仅“全局只有一个同名 profile”
  **不自动通过**，该来源单位条目保留在 `unresolved`。跨学院教师的人事学院取官方
  profile，课程开课单位取课表来源学院，两者分开；每条匹配理由和证据保留在
  `official-teacher-map-all.json` / `cross-unit-audit.json`。
- 本轮先盘点 183 个未解决来源条目，再把其中 153 个无个人 profile/名单无 URL/
  集体页条目全部按课表身份保留；此前 20 个转为 `tt-`，合计 173 个。
- 课表来源学院清晰时，允许“来源学院/教学单位 + 规范姓名”作为课表来源身份：
  `sourceId` 使用独立命名空间 `tt-<collegeCode>-<sequence>`，映射保存在
  `timetable-source-identities.json`；不借用其他学院 profile、不冒充教工号/官方个人 ID，
  名称/学院只表示课表来源/任课单位，职称/campus 留空。
- 同一来源学院内多个页面不一定是多个人：本轮 5 组页面的邮箱/电话/履历/专利一致，
  归并为 5 个官方身份；另 5 组是真同名，按官方明确主讲课程拆为 7 个身份（李莉 2 个、王艳 2 个）。
  3 条按研究方向暂定的课程关系保留 inferred 依据，不按学院+姓名合并两人。
- 外国语 11 名无个人稳定 URL 的候选已按课表身份保留；文法学院 `林超` 仍不借用
  外国语 profile，使用文法学院 `tt-` 身份。
- 化学原 136 人/129 课程/271 关系及 `cce-` sourceId 保持不变。7 名原待映射中，
  孙道峰、张卫东只有跨院同名，按同一规则追加为 `tt-upc-03-001/002`；
  刘相、史德青、徐永强、赵会吉、路帅 5 人按课表身份保留为 `tt-upc-03-003..007`。
