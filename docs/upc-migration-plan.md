## 目标与一期范围

将现有西南交通大学「交大活水」项目改为面向中国石油大学（华东）的课堂反馈应用，复用现有技术栈与评价、审核、积分体系，完整移除 AI 功能。

| 范围 | 一期处理方式 |
| --- | --- |
| 学院与教师查询、教师详情、评价与点赞 | 保留，接入有来源可核对的 UPC 数据 |
| 注册登录、个人中心、签到、评价审核、积分 | 保留，使用独立的新项目配置并验证业务闭环 |
| 课程、学期及开课关系 | 先支持样例范围内真实且有效的关联，再逐批扩展 |
| 六维评分、普通筛选、加权匹配逻辑 | 保留；这些功能不依赖大模型 |
| 依赖本学期课表的选课推荐 | 后续接入；一期隐藏入口和相关宣传，不向用户展示不可用页面 |
| 教务通知抓取与展示 | 后续接入；一期停用旧校抓取配置，隐藏旧通知入口 |
| 经验攻略、历史说明 | 仅保留已经核实适用于 UPC 的内容；没有合适内容时隐藏入口并停止相关扣分 |
| AI 聊天、维护公告、模型服务及提问扣分 | 完整剔除，不引入替代模型或聊天服务 |
| 西南交大的教师、课程、课表、评价、用户积分 | 不迁移、不作为 UPC 正式数据或自动兜底数据 |

一期上线不以取得全校完整教师库、课表或通知为前提。先以可核对的小范围真实数据运行；展示覆盖范围，不把样本数宣称为全校总数。

如果后续明确要求一期提供课表推荐，将 P3-A 所需任务提前到一期验收之前，并同步调整范围、验收和排期。默认按上表执行。
